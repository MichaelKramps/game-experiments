Games that look like work

Kramps Games are free browser games disguised as work. Each one looks like an everyday computer task, like a terminal or a file browser, so you can play at your desk without it looking like a game. They're turn based, so you can leave one alone at any moment, like a boss key that's always on. No ads and no sign up.
