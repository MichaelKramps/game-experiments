Games that look like work

Kramps Games are free browser games disguised as work. Each one looks like an everyday computer task, like a spreadsheet, a terminal or a file browser, so you can play at your desk without it looking like a game. They're turn based, so you can leave one alone at any moment, like a boss key that's always on. No ads and no sign up.

Spreadsheet games

  • Spreadsheet Minesweeper: Minesweeper in a spreadsheet that looks like Excel.
  • Spreadsheet Sudoku: Sudoku puzzles in a spreadsheet that looks like Excel.
  • Spreadsheet 2048: the 2048 number puzzle in a spreadsheet that looks like Excel.
  • Spreadsheet Chess: chess against the computer in a spreadsheet that looks like Excel.
  • Spreadsheet Four in a Row: four in a row against the computer in a spreadsheet that looks like Excel.
  • Spreadsheet Mancala: mancala against the computer in a spreadsheet, with the seeds as numbers.
  • Spreadsheet Word Search: word search puzzles in 40 themes in a spreadsheet that looks like Excel.

Multi-window games

  • Ctrl+Alt+Deal: a video poker deckbuilder that looks like work. Edit your deck to make stronger hands.
  • Yacht: the classic five dice game, with dice as files and a score sheet that looks like Excel.
  • Spades at work: the partnership card game with a computer partner, cards as files and a spreadsheet scorecard.

Terminal games

  • diff guess key: a word deduction game that looks like a terminal. Guess the 5 letter key before your tolerance runs out.

Task board games

  • Solitaire at work: free Klondike solitaire with no ads that looks like a task board.
