Terminal games: games that look like a terminal

Free games played in a terminal window, so they look like work while you play. You type at a prompt and the game answers in plain text, like any other command line session. They're turn based, so you can stop at any moment. Play in your browser with no download, no ads and no sign up.

  • diff guess key: a word deduction game in a terminal. Guess the hidden 5 letter key before your tolerance runs out. Letters that aren't in the key turn red, but it never says which letters are in the right spot.

More games that look like work: spreadsheet games like Minesweeper, Sudoku and chess in a spreadsheet that looks like Excel, Solitaire at work on a task board, and Ctrl+Alt+Deal, a poker deckbuilder. All Kramps Games.
