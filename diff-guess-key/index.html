diff guess key: a word guessing game that looks like a terminal

Guess the hidden 5 letter key before your tolerance runs out. Every guess must be a real 5 letter word. After each guess, the letters that aren't in the key turn red, but the game never says which letters are in the right spot, so you work out the order by guessing words. You start with 15 tolerance, and each wrong guess costs 1 per red letter.

Free, turn based, no ads and no sign up. More games that look like work.
